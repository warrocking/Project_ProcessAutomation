# Project 공정자동화

대한상공회의소 천안기술교육센터에서 수행한 자동화·로봇 프로젝트를 프로젝트별로 정리한 저장소입니다. `Study` 저장소의 학습 기록은 그대로 두고, 여기에는 결과를 설명하고 확인하기 쉬운 프로젝트 자료만 복사했습니다.

## 프로젝트

| 번호 | 프로젝트 | 주요 기술 |
|---:|---|---|
| 1 | [콘솔 키오스크](projects/01_키오스크) | C++, JSON |
| 2 | [PYC 스마트워치](projects/02_PYC_스마트워치) | Python, 센서 제어 |
| 3 | [터틀봇 관제 서버](projects/03_터틀봇_관제서버) | ROS2, TCP, JSON |
| 4 | [타이어 공정 자동화](projects/04_타이어_공정자동화) | ABB RAPID, Python TCP, PLC I/O |
| 5 | [AMR 상·하부체 이송](projects/05_AMR_상하부체_이송) | Python 서버, ABB RAPID, AMR, TCP |

하이브리드 자동차 생산공정 최종 프로젝트는 별도 저장소에서 관리하고 있습니다: [cheonan-hybrid-vehicle-final-project](https://github.com/warrocking/cheonan-hybrid-vehicle-final-project)

## 읽는 순서

각 프로젝트 폴더의 `README.md`에서 개요와 담당 역할을 먼저 확인한 뒤, 코드 폴더로 이동하면 됩니다. 실제 PLC·로봇·AMR 장비가 필요한 코드는 실행 조건을 README에 표시했습니다.

## 원본과의 관계

이 저장소는 `warrocking/Study`의 프로젝트 자료를 복사해 정리한 1차 포트폴리오용 구성입니다. 원본 학습 저장소와 자동 동기화되지 않으며, 원본은 변경하지 않았습니다.
