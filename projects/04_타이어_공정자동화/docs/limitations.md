# 구현 범위 및 개선 과제

이 문서는 복사한 코드와 원본 개발 기록을 대조해 작성했습니다. 이번 작업에서 문제를 수정하거나 실제 장비로 재현 시험을 수행하지 않았습니다.

| 항목 | 코드에서 확인한 내용 | 후속 확인 |
|---|---|---|
| 반복 불량 처리 | `count_White`의 `CASE 2/3/4`가 비어 있음 | 두 번째 이후 불량 제품의 처리 구현·검증 |
| 불량 카운터 | `count_White`의 실행 중 초기화 구문이 없음 | 초기화 시점과 반복 분류 정책 결정 |
| 불량 후 흐름 | 불량 분기에서 `processRunning := FALSE` | 적재 상태와 후속 사이클의 의도 확인 |
| 그리퍼 응답 | `WaitDI`에 시간 제한이 없음 | 센서 무응답 처리 및 복구 절차 검토 |
| PC 수신 대기 | Python은 송신 후 응답을 기다리지만 생산 중 `end` 검사에는 응답 송신이 없음 | 종료 명령·응답·타임아웃 정책 정리 |
| 정지 의미 | TCP `end` 확인은 사이클 사이에서 수행 | 프로그램 종료와 설비 안전 정지의 구분 |

좌표·툴 데이터·I/O 이름은 당시 설비 기준입니다. 복사본에 전체 RobotStudio 스테이션, PLC 래더, 컨트롤러 설정 백업이 포함되어 있지는 않습니다. 다른 설비에 그대로 적용 가능한 완성 패키지가 아닙니다.

DI/DO CSV는 원본을 그대로 보존했습니다. 줄번호와 과거 `CLAUDE.md` 언급은 원본 기록이며, 새 문서의 제한사항 설명은 이 파일을 기준으로 읽으면 됩니다. 런타임 검증 없이 생산 안정성이나 안전 기능의 적합성을 보증하지 않습니다.
