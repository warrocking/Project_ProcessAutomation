# PYC Basic 스마트워치 기능 구현

PYC Basic 장비의 센서와 출력 장치를 Python으로 제어한 프로젝트입니다. 최종 실행 코드는 `src/smart_watch.py`에 두고, 실험용 노트북과 예제 코드는 포트폴리오 저장소에서 제외했습니다.

## 구조

- `src/`: 최종 실행 Python 코드
- `resources/`: 실행에 필요한 설정·측정 자료
- `docs/`: 원격 Jupyter와 작업 환경 안내

## 실행

장비 연결과 PYC Basic 라이브러리가 필요한 프로젝트입니다. 실행 전 `src/smart_watch.py`의 장치 포트와 환경 설정을 확인합니다.
